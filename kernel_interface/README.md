# EEA kernel compatibility

This repository does not vendor or fork the canonical EEA entitlement kernel.

The semantic adapter is compatible with the public EEA Python Reference
Implementation v0.2.0:

https://github.com/kensinro/AIDO-EEA1.0

The adapter produces provisional semantic objects. Evidence contracts,
five-state entitlement semantics, and final scientific adjudication remain
governed by the upstream EEA kernel and Human Gate.
