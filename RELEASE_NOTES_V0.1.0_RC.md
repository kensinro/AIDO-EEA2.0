# Release notes — v0.1.0-rc

This is the first integrated public-safe release candidate for the EEA
supervised semantic-adapter Exp1.

The release preserves three explicit boundaries:

1. EEA kernel semantics are inherited, not redefined.
2. EEA2 semantic outputs are provisional and remain subject to Human Gate.
3. AIT-derived or AIT-inspired elements are orchestration/provenance utilities,
   not scientific entitlement logic.

Exp1 remains final-frozen. The 97-case frozen development/stability universe
must not be used for further tuning.
