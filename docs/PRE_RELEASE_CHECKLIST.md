# Pre-release checklist

- [ ] Confirm repository name.
- [ ] Confirm author names and ORCID(s).
- [ ] Select software license.
- [ ] Confirm whether the flat canonical prompt may be publicly released.
- [ ] Confirm redistribution rights for any source-derived claim corpus.
- [ ] Do not upload restricted PDFs or source passages.
- [ ] Run the synthetic smoke test.
- [ ] Run `build_hash_manifest.py`.
- [ ] Check that no private paths/usernames are embedded.
- [ ] Fill GitHub URL in CITATION.cff.
- [ ] Fill Zenodo metadata.
- [ ] Create tagged release.
- [ ] Record Zenodo DOI in manuscript/SI.
