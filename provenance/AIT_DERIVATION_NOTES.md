# AIT derivation boundary

Some release-governance patterns used in this package were developed alongside
the AIDO Audit/Integration Tool (AIT), including append-only repair lineage,
artifact hashing, freeze records, challenger review, and release-manifest discipline.

No AIT scientific-audit engine or article-level adjudication module is copied
into this EEA semantic-adapter package.

AIT-derived or AIT-inspired elements are used only for orchestration,
provenance, regression, and release governance. They do not redefine the
EEA five canonical claim states, Rmin/Rfull evidence contracts,
contradiction/abstention semantics, or Human Gate authority.
